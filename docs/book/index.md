# The QPLC Book — مقدمه

<div style="text-align:center; font-size:1.1em; margin:20px 0">
<em>یادگیری QPLC با مثال‌های عملی PLC</em>
</div>

این کتاب راهنمای کامل زبان **QPLC** است — یک DSL مدرن و پایتون‌گونه برای برنامه‌نویسی PLCهای سیمنس S7 و کامپایل به **Ladder Logic XML** و **SCL** (قابل ورود به TIA Portal V19). سبک نگارش و ساختار آن از کتاب‌هایی مثل *The Rust Book* و *The C Programming Language* الهام گرفته شده است.

---

## این کتاب چه چیزی به شما می‌دهد؟

- **یادگیری تدریجی**: هر فصل روی یک مفهوم واحد تمرکز می‌کند و مثال‌های کامل دارد.
- **کد واقعی**: تمام نمونه‌ها با کامپایلر واقعی QPLC تست شده‌اند.
- **از صفر تا شبیه‌ساز**: با متغیرهای بولی ساده شروع می‌کند و به struct/enum، رشته‌ها، ماژول‌ها و مدیریت خطا می‌رسد.
- **متناسب با استاندارد IEC 61131-3**: نام‌های استاندارد (TON, TOF, TP, CTU, MIN, MAX, ...) و چند نام مستعار QPLC را معرفی می‌کند.

## پیش‌نیازها

- یک سیستم عامل (Windows با MSYS2، یا Linux)
- CMake ≥ 3.16 و یک کامپایلر C++20
- .NET 8 SDK (برای شبیه‌ساز و Modbus)
- چیزی که همه دارند: صبر 🙂
